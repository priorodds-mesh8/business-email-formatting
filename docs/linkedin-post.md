I built a small agent skill for a problem I kept seeing in AI-written business emails: too many sentences in one block.

Business Email Formatting gives the agent a reusable set of rules:

- Separate topics into short paragraphs.
- Use bullets for related items.
- Make requests and next steps easy to find.
- Preserve facts, dates, prices, and commitments.
- Keep the format intact when the email tool needs HTML or plain text.

It also knows when to leave a short reply alone.

The skill works on its own or alongside an existing writing guide, including STE100. The package includes installation options for Codex, Claude Code, and Cursor.

The code and instructions are available under the MIT license.

GitHub: https://github.com/priorodds-mesh8/business-email-formatting

Try it on a dense email draft. I would like to hear where the format helps and where it needs adjustment.
